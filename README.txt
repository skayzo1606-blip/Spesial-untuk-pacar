WEBSITE ULANG TAHUN ZARA — PAKET LENGKAP DENGAN MUSIK MP3

File dalam paket: index.html, musik.mp3, README.txt.
Website memiliki empat menu (Journey, Moment, Playlist, Gift), galeri lima foto, countdown menuju 15 Oktober 2026, animasi transisi dan hati, serta tombol musik di halaman pertama.

UPLOAD KE ROOT REPOSITORY GITHUB (semua sejajar, tidak dalam folder):
- index.html
- musik.mp3
- IMG-20260922-WA0039.jpg
- IMG-20260923-WA0008.jpg
- IMG-20260926-WA0015.jpg
- IMG_20260817_215817.jpg
- foto-1.jpg

Musik dari file musik.mp3 diputar langsung di dalam website. Nama file harus tetap persis musik.mp3. Browser Android biasanya mengizinkan pemutaran setelah pengguna menekan tombol “Putar Musik & Buka Kejutan” pada halaman pertama. Autoplay sebelum ada interaksi tidak bisa dijamin karena aturan browser.

CARA DEPLOY:
1. Buat repository GitHub baru dengan visibility Public.
2. Upload index.html, musik.mp3, dan kelima foto ke folder root.
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Tunggu deployment selesai lalu buka URL GitHub Pages.
